# RuleForge — Project Proposal (Assignment 2)

**RuleForge: An AI Copilot for Test-Verified Detection Engineering.** An existing LLM turns threat-intelligence text into Sigma detection rules. Each rule is proposed only after deterministic tests replay it against recorded attack logs, benign logs and evasion variants, and a human reviewer approves it.
